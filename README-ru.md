## Введение

Для успешного переноса прежде всего:

1. Установите приложение [Telegram Desktop](https://desktop.telegram.org/).
2. Разверните [TrueConf Server](https://trueconf.ru/products/tcsf/besplatniy-server-videoconferenciy.html) версии 5.5.3 или выше:
   - [для Windows](https://trueconf.ru/blog/baza-znaniy/install-lan-videoconferencing-system) ([видео-инструкция](https://rutube.ru/video/7cf74e21db7b492ed7d0bf7e0190a68f/));
   - для Linux: [Debian](https://trueconf.ru/blog/baza-znaniy/kak-za-15-minut-razvernut-sistemu-videokonferenczij-na-baze-os-linux), [CentOS](https://trueconf.ru/blog/baza-znaniy/ustanovka-trueconf-server-na-centos-stream-9-linux-za-15-minut), [Astra Linux](https://trueconf.ru/blog/baza-znaniy/ustanovka-trueconf-server-na-os-astra-linux-se-za-15-minut), [Альт Сервер](https://trueconf.ru/blog/baza-znaniy/ustanovka-trueconf-server-na-alt-server-linux-za-15-minut), [РЕД ОС](https://trueconf.ru/blog/baza-znaniy/ustanovka-trueconf-server-na-red-os-linux-za-15-minut).
3. Установите на любой ПК (_не там где TrueConf Server_) [Python 3.11](https://docs.python.org/3/using/index.html) или выше.

> [!TIP]
> Данное open-source решение переносит чаты без оригинальной даты и времени отправки сообщения. Если для вас это критично, то обратитесь в [техническую поддержку](https://trueconf.ru/support.html) за помощью.

## Экспорт чата Telegram

После установки и авторизации в приложении Telegram Desktop вам станут доступны все ваши чаты.

> [!TIP]
> Если вы являетесь администратором организации и не имеете доступ к целевым перепискам, то вы можете попросить любого участника чата экспортировать историю вместо вас.

Для экспорта истории:

1. Перейдите в чат и его заголовке нажмите кнопку с тремя точками:

<p align="center"><img width=400px src="docs/tg_more_ru.png"></p>

2. В меню выберите пункт **Экспорт истории чата**.

3. В окне настроек экспорта:

   - отметьте галочками нужные вам медиа;
   - для файлов выставьте ограничение по размеру;
   - в формате укажите **JSON**;
   - укажите путь для сохранения или оставьте по умолчанию `Загрузки/Telegram Desktop/`;
   - настройте диапазон, например с первого сообщения до текущей даты, с 01.02.2022 12:00 по 03.03.2023 19:00 и т.д.

<p align="center"><img width=400px src="docs/export_setting_window_ru.png"></p>

4. Нажмите кнопку **Экспортировать**.

После чего начнется сохранение чата с выбранными настройками. Данное окно можно закрыть, если оно вам мешает.

> [!CAUTION]
> Дождитесь полного завершения операции. Если вы выбрали диапазон дат и видите, что сообщения выгружены, не отменяйте процесс, чтобы избежать повреждения файла.

## Установка и первый запуск

Для скачивания ПО для переноса чатов на главной странице репозитория нажмите кнопку **Code** и выберите **Download ZIP**. После чего распакуйте архив в какую-то директорию.

### Python

Для работы с подготовленными скриптами у вас должен быть установлен Python 3.11 или выше. Для Windows вы можете скачать его с [официального сайта](https://www.python.org/). В Linux и macOS как правило Python уже предустановлен. Проверьте вашу версию с помощью команды:

```bash
> python --version
Python 3.12.4
```

> [!IMPORTANT]
> В случае необходимости обновите вашу версию, иначе скрипт не сработает.

### Настройка окружения

Создайте виртуальное окружение и установите зависимости (препочтительно через [uv](https://docs.astral.sh/uv/)):

 ```bash
 uv sync
 ```

### Запуск программы

Запустите програмное обеспечение с помощью команды в терминале:

 ```bash
 uv run main.py
 ```

У вас откроется окно:

<p align="center">
   <img src="docs/first_screen_ru.png" alt="First Screen" width="800" height="auto">
</p>

Выберите или перетащите папку с экпортом в выделенную область.

## Настройка переноса

### Вкладка "Подключения"

На вкладке **Подключения** доступны следующие настройки: 

<p align="center">
   <img src="docs/tab_connections_ru.png" alt="Connections Tab" width="800" height="auto">
</p>

1. Настройки сервера TrueConf:

   - адрес сервера: доменное имя или IP-адрес;
   - веб-порт, используемый для HTTPS соединения (по умолчанию, `443`);
   - проверка SSL-сертификата: **включена** для доверенных, **выключена** для самоподписанных;
   - токен доступа из **Веб → Безопасность**. Нужен исключительно для регистрации пользователей на сервере, в случае, если у вас новая инсталляция.

1. Настройки бота Telegram. Эти настройки нужны для получения **@username** и **реального имени** участника Telegram чата, что существенно упрощает идентифицировать человека и связать его с существующим TrueConf ID.
Если в вашем чате находится достаточно большое кол-во участников, то:

   1. Создайте бота через [BotFather](https://t.me/BotFather) и укажите его токен в поле **Токен из BotFather**;
   2. Добавьте бота в чат и выдайте ему права администратора;
   3. C помощью бота [@userinfobot](https://t.me/userinfobot) определите ID чата и укажите его в соответствующем поле.

> [!TIP]
> Кнопка **Применить** сохраняет настройки во внутренний файл, так что вы можете готовится к переносу чата в течение продолжительного времени.

### Вкладка "Чат"

На вкладке **Чат** укажите следующие настройки:

<p align="center">
   <img src="docs/tab_chat_ru.png" alt="Connections Tab" width="800" height="auto">
</p>

#### Параметры чата

В этом разделе укажите:

- название нового чата.
- владельца чата. Желательно указать TrueConf ID. Этот пользователь должен быть в таблице в разделе **Пользователи**. 
- тип чата. Для группы с темами (топик, форум) выберите **Супергруппа**, а также укажите **Шаблон темы**. 

> [!CAUTION]
> Не изменяйте значения подстановочных переменных `{topic}` или `{supergroup}`.
> Вы можете задать свой формат, например, поменять их местами `{supergroup} | {topic}` или убрать `{supergroup}`. 
> По умолчанию название подгруппы будет такое `Название топика | Название чата`.

#### Опции переноса

#### Конвертация голосовых сообщений

Поскольку приложение Труконф не поддерживает формат **ogg**, используемый в Telegram,голосовые сообщения могут быть автоматически сконвертированы в видео формата **mp4** с обложкой (которую вы заменить на свою). Это позволит вам прослушивать их через встроенный просмотрщик Труконф.

> [!IMPORTANT]
> Для работы этой функции в системе должен быть установлен FFmpeg (добавлен в PATH) с поддержкой фильтра drawtext для отрисовки даты.
> Перед включением функционала проверьте готовность системы командой:
>
> ```bash
> uv run check_ffmpeg.py
> ```
>
> Если проверка прошла успешно (FFmpeg OK ✅), можно приступать к настройке.

Также в правом нижнем углу будет добавлен контекст: источник и время записи оригинала.

<p align="center">
<img src="docs/example_voice_message_ru.png" alt="Chatbot Auth Page" width="800" height="auto">
</p>

#### Конвертация анимированных стикеров

Анимированные стикеры Telegram представлены в формате **.tgs**. Это представляет собой архив с анимацией в формате [lottie](https://lottie.github.io/).

Если в вашем чате активно пользовались анимированными стикерами, то вы можете их сконвертировать в формат **webp**, который поддерживает Труконф. Если не включать конвертацию, то такие сообщения будут отправлены просто как emoji.

> [!IMPORTANT]
> Конвертация задествует системные библиотеки, которые должны быть доступны в системе на момент запуска скрипта по переносу чата.

##### Windows

Требуется системная библиотека **Cairo**. Установить ее можно с помощью [MSYS2](https://www.msys2.org/). После этого:

1. Запустите команду:

   ```bash
   pacman -Syu
   ```

2. Если в конце консоль напишет что-то вроде: `warn: terminate MSYS2 without returning to shell and check for updates `again` — перезапустите терминал.

3. Установите библиотеку:

   ```bash
   pacman -S mingw-w64-x86_64-cairo
   ```

### Дата и время сообщений

Данная версия программы не поддерживает перенос сообщений с оригинальным временем отправки. Все сообщения отправляются с временем работы скрипта. Если оригинальное время для вас имеет решающее значение, то вы можете:

- активировать флажок, настроить таймзону (часовой пояс) и подпись. В таком случае к каждому сообщению будет добавлена текстовая подпись с датой и временем отправки `Отправлено: 01.09.2025 14:10:00 +0300`.
- обратиться в [техническую поддержку Труконф](https://trueconf.ru/support.html) за помощью.

Если пользователей еще нет на TrueConf Server, то вы можете их добавить. Об этом [читайте ниже](#регистрация-пользователей-в-trueconf-server-без-ldap).

#### Регистрация пользователей в TrueConf Server (без LDAP)

Для переноса чатов из Telegram в TrueConf необходимо, чтобы все пользователи участвующие в общении были зарегистрированы в TrueConf Server.
Если вы **не используете LDAP**, то вы можете осуществить регистрацию пользователей прямо на вкладке **Пользователи**.

> [!IMPORTANT]
> В случае настроенной инфраструктуры перейдите к следующему разделу.

Для регистрации пользователей укажите их TrueConf ID, отображаемое имя и Email домен. Чтобы ускорить перенос чатов, вы можете задать всем пользователям **общий пароль** в поле **Пароль для регистрации**.

Для аутентификации запроса на регистрацию необходимо использовать `access_token` API TrueConf Server. Получить его можно одним из следующих способов:

1. В панели управления TrueConf Server.

   Перейдите в раздел **Веб → Безопасность** и скопируйте токен API.

> [!CAUTION]
> Такой токен не имеет срока действия по умолчанию, предоставляет доступ ко всему API сервера и должен храниться как секрет администратора.

2. Через OAuth-приложение (рекомендуется).

   Создайте [OAuth-приложение](https://trueconf.ru/docs/server/ru/admin/api/), выдайте ему только необходимые права и выполните запрос к `https://domain.name/api/v4/token`, чтобы обменять `client_id` и `client_secret` на `access_token`.

> [!NOTE]
> OAuth-токен по умолчанию действует 1 час, что делает этот вариант более безопасным для миграционных и автоматизированных сценариев.

Вставьте токен в поле **Токен доступа (для регистрации пользователей)** в разделе **Подключения**.

После внесения всех данных нажмите кнопку **Применить**, а потом активируйте регистрацию с помощью кнопки <span>
   <img src="docs/reg_users_button.png" alt="Registration Button" width="36" height="auto"></span> в правом верхнем углу. Для каждого пользователя вы получите ответ типа:

```
✅ Успешное добавление

⚠️ Пользователь уже существует

🔴 Ошибка
```

### Для настроенной инфраструктуры (при использовании LDAP)

Если в вашей инфраструктуре используется LDAP и требуется перенести чат с большим количеством участников — более 20 человек, — ручной сбор токенов для каждого пользователя может оказаться слишком трудоёмким и неудобным.
В таком случае рекомендуем выполнять перенос в нерабочее время: временно переключить TrueConf Server с **LDAP** на **Registry**.
После этого можно зарегистрировать пользователей, как описано в разделе «[Регистрация пользователей в TrueConf Server (без LDAP)](#регистрация-пользователей-в-trueconf-server-без-ldap)» и выполнить миграцию чата.
Когда перенос будет завершён, сервер можно снова переключить обратно на LDAP.

Рекомендуем следующий порядок действий:

1. Укажите **общий пароль** для всех в поле **Пароль для регистрации**.

2. Для каждого пользователя (Telegram ID) укажите корректный TrueConf ID.

3. В нерабочее время временно переведите TrueConf Server из режима **LDAP** в режим **Registry** без _автоматической миграции пользователей_.
4.	Зарегистрируйте пользователей на сервере, как показано в разделе «[Регистрация пользователей в TrueConf Server (без LDAP)](#регистрация-пользователей-в-trueconf-server-без-ldap)».
5.	Выполните [миграцию чата](#перенос-чата).
6.	После успешного завершения миграции переключите сервер обратно на **LDAP**.

Если переключение на **Registry** невозможно даже на короткое время, используйте инструкцию из следующего раздела.

### Получение `токена` для авторизации в API чатов (если невозможно переключиться с LDAP на Registry)

Для авторизации в API чатов требуется `Токен`. Чтобы его получить, необходимо отправить **POST-запрос** с логином и паролем учетной записи TrueConf Server (см. [документацию](https://trueconf.ru/docs/chatbot-connector/ru/connect-and-auth/#access-token)).

Однако в инфраструктуре с LDAP возникает практическая проблема:
администратор TrueConf Server, как правило, не знает паролей пользовательских учётных записей, поскольку аутентификация выполняется через доменную учётную запись.
Запрашивать у сотрудников их пароль от корпоративной учётной записи небезопасно и недопустимо, так как фактически это означает запрашивать доступ к их доменному аккаунту (все равно, что попросить "ключи от квартиры, где деньги лежат".)

Поэтому команда Труконф подготовила [HTML-страницу](chatbot/ru/index.html), которая упростит данный процесс. Что с ней делать? Просто добавить на TrueConf Server или на нужную ноду TrueConf Enterprise.

#### Добавление страницы на веб-сервер TrueConf

1. Скопируйте папку [`chatbot`](chatbot) по пути: 

   **Windows (PowerShell):** 

   ```shell
   Copy-Item -Path "D:\chatbot" -Destination "C:\Program Files\TrueConf Server\httpconf\site" -Recurse
   ```

   **Linux:** 

   ```shell
   sudo cp ~/chatbot /opt/trueconf/server/srv/site/
   ```

2. Перезагрузите службу **TrueConf Web Manager**:
   
   **Windows (PowerShell):** 

   ```shell
   Restart-Service -Name "TrueConf Web Manager"
   ```

   **Linux:** 

   ```shell
   sudo systemctl restart trueconf-web
   ```

> [!CAUTION]
> При обновлении TrueConf Server директория `chatbot` будет удалена с сервера.

#### Инструкция по получению токена

Попросите каждого пользователя, которого добавляете в чат, получить access_token следующим образом:

1. В браузере перейдите по адресу `https://server.address/chatbot/ru/index.html`. 
   Укажите логин (TrueConf ID) и пароль в полях ввода и нажмите **Получить токен**:

   <p align="center">
     <img src="docs/chatbot_auth_ru.png" alt="Chatbot Auth Page" width="800" height="auto">
   </p>

2. В случае успеха у вас отобразится токен. Скопируйте или скачайте его файлом для дальнейшей передачи вашему администратору:

   <p align="center">
     <img src="docs/chatbot_token_ru.png" alt="Chatbot Auth Page" width="800" height="auto">
   </p>

#### Что делать с `токеном` после получения

Для каждого пользователя заполните столбец `Токен` в разделе **Пользователи**.

> [!IMPORTANT]
> Важно убедиться, что токен вставлен в блок именно того пользователя, которому он принадлежит, иначе при переносе сообщения могут быть отправлены от неверного имени.

После того как токены будут заполнены для всех участников, можно переходить к следующему этапу — [переносу чата](#перенос-чата).

## Перенос чата

Для запуска переноса сохраните настройки нажатием кнопки **Применить**. После чего кнопка **Начать перенос** станет активна.

> [!WARNING]
> Для чатов с типом `группа`,`супергруппа` и `канал` при каждом запуске переноса будет создаваться новый экземпляр чата.

В случае успешного переноса у вас появится копия чата Telegram:
